# Base de dados

Baixe o arquivo `IOT-temp.csv` no Kaggle:

https://www.kaggle.com/datasets/atulanandjha/temperature-readings-iot-devices

Depois coloque o arquivo nesta pasta com este nome:

```text
data/IOT-temp.csv
```

O CSV não é versionado no Git para evitar deixar o repositório pesado. O arquivo
`exemplo.csv` permite testar o pipeline antes de baixar a base completa.
